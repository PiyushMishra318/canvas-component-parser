Canvas Component Parser

Parse HTML to AST/React, compose component JSON to a page, or list data-component layers.

How it works

  1. AST — Himalaya parses HTML into a JSON tree.
  2. React — AST is transformed to JSX-style markup with className.
  3. Compose — A JSON array of components is stitched into one HTML document.
  4. Split — Lists named layers from data-component attributes in a template.
