How it works

  1. Input — Paste HTML, load a sample file, or paste canvas component JSON.
  2. Parser — Himalaya builds an AST; compose/split modes use the canvas document format.
  3. Parse output — AST, React, composed HTML, or split layer names (tabs below).
  4. Canvas preview — Draw commands (fillRect, fillText, rounded rects) visualize boxes, text, and buttons from the parsed structure.
